# shell_sensitive_script (Resource)

The _Shell_ sensitive script resource (`shell_sensitive_script`) runs configured commands during the _Terraform_ lifecycle; it behaves the same as `shell_script` except that `output` is marked as sensitive.

This resource supports the same configuration, environment variables, and capabilities as [`shell_script`](./script.md). The only difference is that the `output` attribute is marked as sensitive, so _Terraform_ redacts it in plan and apply output and any value derived from it is also treated as sensitive. Sensitive values are still stored in plain text in _Terraform_ state, so the state must be protected accordingly. Avoid writing secrets to stdout/stderr when provider `log_output` is enabled, as logged lines are not redacted.

## Example Usage

```terraform
resource "shell_sensitive_script" "create_key" {
  os_commands = {
    default = {
      create = {
        command = <<-EOF
          set -euo pipefail
          key="$(openssl rand -hex 32)"
          printf '{"key":"%s"}' "$${key}" > "$${TF_SCRIPT_OUTPUT}"
        EOF
      }
      read = {
        command = <<-EOF
          set -euo pipefail
          printf '%s' "$${TF_SCRIPT_STATE_OUTPUT}" > "$${TF_SCRIPT_OUTPUT}"
        EOF
      }
      update = {
        command = <<-EOF
          set -euo pipefail
          printf '%s' "$${TF_SCRIPT_STATE_OUTPUT}" > "$${TF_SCRIPT_OUTPUT}"
        EOF
      }
      delete = {
        command = ""
      }
    }
  }
}

output "key" {
  value     = shell_sensitive_script.create_key.output.key
  sensitive = true
}
```

### Optional

- `environment` (Map of String) The environment variables to set when executing commands; to be combined with the OS environment and the provider environment.
- `inputs` (Dynamic) Inputs to be made available to the script; these can be accessed as JSON via the `TF_SCRIPT_INPUTS` environment variable.
- `timeouts` (Attributes) (see [below for nested schema](#nestedatt--timeouts))
- `triggers` (Dynamic) Allows specifying values that trigger resource replacement when changed.
- `working_directory` (String) The working directory to use when executing the commands; this will default to the _Terraform_ working directory.

### Read-Only

- `output` (Dynamic, Sensitive) The JSON output from plan, create, read, or update as a structured type. The prior value is available to plan (when prior state exists), read, update, and delete commands as JSON via `TF_SCRIPT_STATE_OUTPUT`. A top-level `__meta` key is reserved for provider metadata and is removed from output.
- `output_drift` (Boolean) True when the read command reported `__meta.output_drift_detected = true`. This signals output drift; it does not by itself guarantee that an update command will repair the external object.
